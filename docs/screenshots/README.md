# Current app screenshots

Captured from the actual React Native web application in the successful release browser-test run for v0.3.0-beta.30, using synthetic training/test-shop fixtures. These are not HTML design proposals or screenshots of customer records. Captures illustrate workflows; stock, names, counts and permissions vary by shop.

The browser uses IndexedDB. These captures do not demonstrate native camera, SQLCipher, LAN discovery or physical printer behavior. Those require installed-device testing.

Source tests: [browser suites](../../tests/e2e/). Older files under `docs/previews` and HTML mockups are historical design material; the main README uses this directory for current screens.
